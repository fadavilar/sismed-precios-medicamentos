# Precios de medicamentos en Colombia (SISMED)

Sitio publicado de la app de precios y mercado de medicamentos con datos de SISMED (MinSalud). La app y los datos están cifrados y se abren con contraseña.

Este repositorio solo contiene la versión publicada y cifrada. No lo edites a mano: lo genera y actualiza automáticamente el repositorio fuente (privado).
